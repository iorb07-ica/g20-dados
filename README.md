# G20 Dados

Dados públicos usados pela Plataforma G20 Masterclass, atualizados por rotinas automáticas (GitHub Actions):

| Pasta | O que tem | Rotina |
|---|---|---|
| `dados/proventos/br/` | Proventos e eventos (desdobramentos, grupamentos, bonificações) de ações, FIIs, Fiagros e FI-Infra da B3, um arquivo por ativo | `proventos-br.yml` |
| `dados/proventos/codigos-antigos.json` | Códigos antigos da B3 (trocas de ticker, incorporações, saídas) | manual |
| `dados/tesouro/` | Preço oficial dos títulos do Tesouro Direto (Tesouro Transparente) | `tesouro-precos.yml` |
| `dados/bcb/` | Séries do Banco Central (CDI, Selic, IPCA, IGP-M, poupança, PTAX) e índices da B3 | `bcb-indices.yml` |

Publicado em https://iorb07-ica.github.io/g20-dados/. Só dados públicos de mercado: nenhum dado de usuário fica aqui.
